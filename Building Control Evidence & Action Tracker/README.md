# 🏗️ Building Control Evidence & Action Tracker

## Overview

An Excel-based tracker I developed to organise Building Control evidence requirements, responsibilities, actions and review status in one place.

The idea is simple: Building Control can generate a lot of information across drawings, specifications, certificates, comments and evidence requests. This workbook structures that information so it is easier to see **what is required, who is responsible, what is outstanding and what has been signed off**.

## What It Tracks

- Building Regulations category
- Evidence or information required
- Requirement description
- Duty holder
- Responsible person and organisation
- Current status
- Enquiry and required-by dates
- Comments and actions
- Evidence required for close-out

Example topics include structural information, fire safety, ventilation, drainage, accessibility, energy performance, Regulation 7, Regulation 38 and completion documentation.

## Portfolio Data

The **workbook structure, tracking approach and Excel functionality were designed and built by me**.

The portfolio version uses **AI-generated fictional example data** so the workbook can demonstrate realistic functionality without publishing real clients, projects, colleagues or commercially sensitive information.

All example projects, people, organisations, dates, evidence records and compliance outcomes are synthetic.
