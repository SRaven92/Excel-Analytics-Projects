# 🏢 Multi-Project Building Control Dashboard

## Overview

An Excel-based portfolio dashboard I developed to bring Building Control information from multiple projects into one reporting environment.

The system combines individual project checklists, contact and responsibility information, issue registers and progress data, making it easier to see **which projects are progressing, where issues remain open and which areas require attention**.

The portfolio version demonstrates the system across 10 fictional projects.

## What It Tracks

- Building Control checklist requirements
- Checklist completion and status
- Open and resolved issues
- Issue dates, responses and follow-up actions
- Project contacts and responsibilities
- Project start and completion dates
- Individual project progress
- Portfolio-level performance

The workbook provides both detailed project views and a combined overview across Projects A–J.

## Dashboard & Reporting

The dashboard includes:

- Selected project detail
- Checklist completion by project
- Open issue counts
- Project status charts
- Portfolio summary across all 10 projects
- Illustrative completion trends
- Consolidated issue reporting

The portfolio example contains 566 synthetic checklist records and 65 fictional project issues, demonstrating how the workbook behaves with a larger dataset.

## Portfolio Data

The **workbook structure, formulas, calculations, dashboards, project templates and reporting logic were designed and built by me**.

For the public portfolio version, **AI was used to generate fictional example data** across the 10 projects. This allows the system to demonstrate realistic volumes, different project statuses and issue scenarios without exposing real clients, projects, colleagues or commercially sensitive information.

All projects, organisations, contacts, dates, checklist statuses, issues, responses and progress figures are synthetic.

> Building Control requirements and example evidence are included to demonstrate the functionality of the system. They should be independently verified against current legislation, Approved Documents, guidance and project-specific requirements before practical use.
