# 🏗️ Building Regulations & CDM Compliance Dashboard

## Overview

An Excel-based compliance dashboard I developed to bring Building Regulations, CDM and selected fire-safety requirements into one structured reporting system.

The workbook is designed to make a large amount of regulatory information easier to manage by linking detailed compliance records with a higher-level dashboard showing progress, status and areas requiring attention.

## What It Tracks

- Building Regulations requirements
- CDM requirements
- Selected fire-safety requirements
- Duty-holder responsibilities
- Applicability and compliance routes
- Design guidance and strategy
- Evidence and document references
- Progress and status
- Actions requiring attention

## Excel Skills Demonstrated

- Structured Excel tables
- XLOOKUP
- Cross-sheet data relationships
- Data validation
- Conditional formatting
- Progress calculations
- Dashboard design
- Charts and visual reporting
- Compliance and action tracking
- Regulatory information management

## Portfolio Data

The **workbook structure, formulas, calculations, dashboard and reporting logic were designed and built by me**.

For the public portfolio version, **AI was used to generate fictional example projects, responsibilities, evidence records, actions and compliance outcomes**. This allows the workbook to demonstrate realistic functionality without using actual client, project or commercially sensitive information.

All example data is synthetic.

> **Important:** Regulatory, legislative and standards references within this workbook are included to demonstrate how this type of information can be structured and reported. The workbook is not a current legal register, and all requirements should be independently verified against current legislation, Approved Documents, guidance and project-specific requirements before practical use.
