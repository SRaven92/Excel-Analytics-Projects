# 📐 Design Document & Drawing Register

## Overview

An Excel-based document register I developed to manage and review multidisciplinary design information across a construction project.

The workbook brings drawings, specifications, reports and other technical documents into one structured register, making it easier to track **what has been issued, the current revision and status, who produced it, what standards are referenced and where further review or coordination is required**.

## What It Tracks

- Design discipline
- Document reference and description
- Document type
- Status and purpose of issue
- Revision
- Issue and received dates
- Author and organisation
- Standards referenced
- Reference review status
- Design coordination comments
- Fire / specialist comments
- Review notes

The portfolio example includes architectural, structural, M&E, fire, sprinkler, process and as-built design information.

## Reference Review

The register uses simple review categories to identify the status of standards references:

- ✅ **Reference complete**
- ⚠️ **Reference incomplete**
- 🔎 **Review required**
- ❌ **Reference mismatch**

These statuses relate to the quality and completeness of the reference recorded within the document. They do **not** represent technical approval or certification of the design.

## Portfolio Data

The **workbook structure, review process, formatting and Excel functionality were designed and built by me**.

For the public portfolio version, **AI was used to generate fictional document records and supporting example information**. This allows the register to demonstrate realistic multidisciplinary design scenarios without exposing real projects, clients, consultants or commercially sensitive information.

All projects, organisations, document references, dates, revisions, standards-review outcomes and comments are synthetic.

> Standards references and review outcomes are included for demonstration purposes only. Current editions, amendments and project-specific requirements should be independently verified against authoritative sources before practical use.
